# claude-mods

Mods for Claude Code, free and MIT licensed.

| Mod | What it does |
|---|---|
| [backseat](plugins/backseat) | A fake Twitch chat that reacts live to what Claude is doing. |

## Install

```
/plugin marketplace add anunstayblemind/claude-mods
/plugin install backseat@claude-mods
```


Issues and suggestions are welcome.
